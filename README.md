# Expense Tracker

A simple web app to track daily expenses, built with Python, Flask and SQLite.

## Features
- Add new expenses with amount, category, date and note
- View all expenses with total amount
- Edit and delete expenses

## Tech Stack
- Python
- Flask
- SQLite
- HTML

## How to Run
1. Clone the repo:
   git clone https://github.com/Shubham-cmd-ui/expense-tracker.git
2. Install Flask:
   pip install -r requirements.txt
3. Run the app:
   python app.py
4. Open in browser: http://127.0.0.1:5000
